# MagicChair Safety

MagicChair is an experimental assistive mobility project. Safety must take priority over autonomous behavior, speed, or convenience.

## Core Principles

- Normal stopping should use smooth, controlled deceleration.
- Speed can be reduced gradually to zero using the slow-down control.
- Sudden stopping should be reserved for situations requiring rapid braking.
- Acceleration and deceleration should be limited to reduce sudden movement.
- Manual controls must be able to override autonomous navigation.
- Autonomous movement must stop or slow when an unsafe condition is detected.
- The physical system must eventually include an independent emergency-stop mechanism.
- Software failure must not result in uncontrolled movement.
- Physical prototypes must be tested without a person before any human testing.

## Current Development Stage

MagicChair is currently a software prototype.

No current code should be considered safe or suitable for controlling a real mobility device.
