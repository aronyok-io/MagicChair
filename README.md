# MagicChair
An experimental assistive mobility project to make the daily life of my grandmother easier.

Goal:
To create a mobility chair that can be controlled through:
1. Physical directional controls.
2. Voice commands
3. Autonomous indoor navigation
4. Emergency/Manual Override

My strategy to approach this project:
Software then Stimulation then small robot then full-scale prototype

To ensure its safety no human testing until the physical system has undergone proper mechanical, electrical and software safety testing.
